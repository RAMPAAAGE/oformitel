# Оформление «Газета»

Программа выглядит как свежий номер газеты: название — шапка между двойными линейками,
вкладки — рубрики через вертикальную черту, разделы — статьи с жирной линейкой сверху.

- **Шрифт:** Old Standard TT везде (классический русский наборный шрифт), лежит в `electron/build/fonts`.
- **Цвета:** газетная бумага `#e6e4de` / `#f3f2ee`, краска `#141414`, красный «срочной новости» `#a3121b`
  для ссылок, активной рубрики и ошибок.
- **Кнопки:** главная — чёрная, подписи капителью; второстепенные — контурные.
- **Контраст:** текст 16:1, ссылки 7:1, подсказки 8:1.
- Переключатель темы скрыт: газета всегда светлая.
