# Оформитель документов

Настольная программа для приведения файлов Word (`.docx`) к нужному оформлению. Пользователь выбирает документ и профиль, а программа настраивает поля страницы, шрифт, межстрочный интервал и отступ первой строки.

Интерфейс открывается в окне Electron. Flask работает только внутри программы как локальный помощник: браузер и отдельное окно сервера пользователю не нужны.

При сборке backend упаковывается в отдельный исполняемый файл. Поэтому готовому приложению не нужен установленный Python.

## Что нужно для разработки

- Python 3.10 или новее;
- Node.js 20 или новее — для Electron;
- Docker Desktop — только для запуска backend в контейнере.

Во всех командах для macOS ниже предполагается, что проект находится здесь:

```bash
~/Documents/project 2/oformitel
```

Если ты перенесёшь папку проекта в другое место, замени этот путь на свой.

## Запуск backend на компьютере

Открой Терминал и вставь команды по порядку:

```bash
cd ~/Documents/project 2/oformitel/backend
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 app.py
```

Последняя команда запустит backend. Открой в браузере `http://127.0.0.1:5000`. Чтобы остановить его, нажми `Control + C` в Терминале.

В Windows используйте эти команды:

```bat
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Если команда `py` не найдена, замените её на `python`. После запуска откройте `http://127.0.0.1:5000`.

## Как пользоваться

Программа состоит из трёх вкладок.

**Вкладка «Документ»**
1. Выберите файл `.docx`.
2. Выберите профиль оформления («Инженеры будущего» или «ГОСТ 7.32-2017»).
3. Отметьте нужные автоисправления: нумерация страниц, точки в оглавлении, оформление титульного листа.
4. Нажмите «Оформить документ» и скачайте результат.

**Вкладка «Титульный лист»**
1. Заполните организацию, название работы, участников, руководителя, город и год.
2. Нажмите «Создать титульный лист» — программа соберёт готовый `.docx` с нуля.

**Вкладка «Презентация»**
1. Выберите файл `.pptx`.
2. Нажмите «Проверить презентацию» — появится список замечаний по номерам слайдов (точка в конце заголовка, слишком длинный текст на слайде).

При необходимости на вкладке «Документ» раскройте блок «Создать свой профиль», заполните поля и сохраните его. Новый профиль появится в списке.

## Запуск backend через Docker

Docker используется только для разработки и тестирования backend, а не для передачи программы пользователю.

Открой Терминал и выполни:

```bash
cd ~/Documents/project 2/oformitel
docker compose up --build
```

Затем откройте `http://127.0.0.1:5000`. Остановить контейнер можно сочетанием `Ctrl+C`.

## Запуск настольного приложения Electron

Сначала один раз создай виртуальное окружение и установи библиотеки из раздела «Запуск backend на компьютере». Если ты запускал backend, останови его сочетанием `Control + C`. Затем открой новый Терминал и вставь:

```bash
cd ~/Documents/project 2/oformitel/backend
source .venv/bin/activate
cd ../electron
npm install
npm start
```

Electron самостоятельно запустит Flask и покажет интерфейс в отдельном окне. Отдельно выполнять `python3 app.py` перед этим не нужно.

## Сборка приложения

### Сборка одним запуском на macOS

Дважды кликни файл `Собрать_приложение.command` в папке `oformitel`. Также можно запустить его из Терминала:

```bash
cd ~/Documents/project 2/oformitel
./Собрать_приложение.command
```

Скрипт использует уже установленные Python, Node.js и библиотеки. Если чего-то не хватает, он установит недостающие компоненты. Когда Homebrew отсутствует, скрипт сначала попросит разрешение на его установку. При успешной сборке Finder откроет папку `~/Documents/project 2/билды`, а вкладка Terminal со скриптом закроется автоматически.

### Ручная сборка

Открой новый Терминал и вставь команды по порядку:

```bash
cd ~/Documents/project 2/oformitel/backend
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt -r requirements-build.txt
cd ../electron
npm install
npm run dist
```

Если виртуальное окружение `.venv` уже создано, первую команду `python3 -m venv .venv` можно пропустить.

## Проверка проекта

Запусти из папки `oformitel`:

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют открытие интерфейса, создание титульного листа, обработку DOCX, анализ PPTX и проверку пустых данных.

В Windows используйте:

```bat
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt -r requirements-build.txt
```

Если команда `py` не найдена, замените её на `python`.

Готовые файлы появятся в папке `~/Documents/project 2/билды`:

- в Windows — установщик `.exe`;
- в macOS — образ `.dmg`, внутри которого находится приложение `.app`.

Команда `npm run dist` сначала упакует Python-backend с помощью PyInstaller, а затем Electron Builder создаст установщик. Собирайте Windows-версию на Windows, а macOS-версию на macOS: backend должен быть собран под ту же операционную систему и архитектуру процессора, что и итоговое приложение (например, macOS Apple Silicon — на Mac с Apple Silicon).

После установки готовая программа сама сохраняет загруженные файлы, результаты и созданные профили в пользовательской папке приложения. Она не записывает данные в папку установки, поэтому корректно работает и из `Program Files`, и из `.app`.

Файл `electron/build/index.html` один и тот же для Flask и Electron: Flask отдаёт его как страницу, а Electron показывает эту страницу в своём окне. Во время сборки `backend/build_backend.py` кладёт этот интерфейс внутрь исполняемого backend-файла.
